# Wireframes

This folder contains wireframe artifacts for the Guess That Pokémon game.

## Included files
- `home-wireframe.svg` — wireframe for the home selection screen
- `game-wireframe.svg` — wireframe for the main gameplay screen

## Notes
These wireframes are provided as visual layout references for the game UI. They can be replaced by Sketch Lab exports if you have Sketch Lab source files.
