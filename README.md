# Guess That Pokémon! 🎮

An interactive, fast-paced web arcade game that puts a modern spin on the classic *"Who's That Pokémon?"* television segment. Built completely with clean, self-contained HTML5, CSS3, and native JavaScript, this responsive minigame challenges your Poké-knowledge while introducing a competitive in-game economy.

---

## 🌟 The Twist & Target Audience

### The Twist: Guessing Meets E-Commerce!
Unlike standard trivia games where you just tally correct answers, **Guess That Pokémon!** introduces a dynamic currency system. 
* Every correct silhouette guess earns you **+$10 in pocket cash**. 
* Getting a question wrong takes you to a failure screen where you must decide to spend valuable resources to try again or take a strategic skip.
* Accumulate your earnings to unlock collectible items and badges in the **integrated Arcade Shop**, tracking your journey from a local novice to a Master Trainer.

### Who Is This For?
This game is designed for **three types of players**:
1. **Classic Fans:** Anyone looking for an instant wave of nostalgia using authentic Gen-1 through Gen-4 official character silhouettes.
2. **Casual Gamers:** Players looking for an unblocked, lightweight web game that loads instantly on desktop, tablets, or mobile phones without installation.
3. **Aspiring Developers:** An excellent boilerplate reference showing clean state-driven UI management, CSS silhouette filters, and robust defensive programming practices.

---

## 🕹️ How to Play

The entire game is played using an intuitive, layout-locked mobile card structure designed to minimize clicks and maximize engagement.
